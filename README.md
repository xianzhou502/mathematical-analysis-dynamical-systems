# Mathematical Analysis and Dynamical Systems

## Topics Covered

### Periodic Points

The project begins by discussing periodic points, which describe values in a function or map that repeat after a certain number of iterations.

A point is periodic if repeated application of a function eventually returns the point to a previous state. This idea is important in dynamical systems because it helps describe predictable patterns within systems that evolve over time.

The report includes an example of a piecewise linear map with a cycle of length six, showing how periodic orbits can be used to understand repeated system behaviour.

### Chaotic Systems

The project also introduces chaotic systems, which are mathematical systems that may appear unpredictable even though they follow deterministic rules.

A key idea in chaos theory is sensitivity to initial conditions. Small differences in starting values can lead to very different outcomes over time.

The report discusses topological transitivity and uses contradiction-based reasoning to explain why a topologically transitive system on a finite space must either be infinite or consist of a single orbit.

### Fixed Points

The project explains fixed points as values that remain unchanged when a function is applied.

A fixed point satisfies:

[
f(x) = x
]

Fixed points are important because they represent stable or unchanged states in mathematical systems. They are frequently used in dynamical systems, equilibrium analysis, optimisation, and numerical methods.

### Differential Equations

The report connects fixed points with differential equations, which describe how quantities change over time.

Differential equations are used to model many dynamic processes, including motion, population growth, physical systems, economic systems, and natural phenomena.

The project discusses how derivatives can represent velocity, acceleration, and rates of change.

### Linear Differential Equations

The project also includes linear differential equations, where the rate of change is proportional to the current state of the system.

Linear differential equations are an important foundation for modelling predictable change over time and are widely used in applied mathematics, physics, engineering, economics, and data-driven modelling.
